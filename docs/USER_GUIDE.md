# Novda Hisob-Kitob — Foydalanuvchi Qo'llanmasi

## 1. Dasturni O'rnatish va Faollashtirish
1. `Novda-hisob-kitob-Setup.exe` faylini o'rnating.
2. Dastur ochilganda sizga kompyuteringizning **HWID apparat kodi** ko'rsatiladi (masalan: `9EE3-D5A1-F461-BC42`).
3. Telegram botga (`@hisobmonitoringbot`) avtomatik bildirishnoma boradi. Admin tegishli rolni tanlaydi (`Admin`, `Type`, `Print`).
4. Berilgan faollashtirish kalitini (`ACT-ADMIN-...`) dasturga kiritib, **«Faollashtirish»** tugmasini bosing.

---

## 2. Rollar Vazifalari
- **👑 Admin:**
  - Ishchilarni qo'shish, o'chirish va stajlarni boshqarish.
  - Yangi modellar ochish va operatsiyalarni belgilash.
  - Oylik davrni yopish va zaxira nusxa yaratish.
  - Admin Panel orqali yangi kompyuterlarga kalit yaratish va oflayn navbatni sinxronlash.
- **⌨️ Type:**
  - Kunlik kiritilgan sonlarni (hisob miqdorlarini) to'ldirish.
  - Ishchilarning jami ishlagan summalari va Umumiy jadvalni ko'rish.
- **🖨️ Print:**
  - Pattalarni shakllantirish va qog'ozga chop etish.
  - Cheklarni monitoring qilish.

---

## 3. Oflayn va Onlayn Ishlash
- Sarlavhadagi **«Online»** belgisi — tizim Firebase bulutiga ulanganini bildiradi.
- Agar internet uzilsa, belgi sariq yoki qizil bo'lib, **«Oflayn»** rejimga o'tadi.
- Oflayn paytda bemalol ishlashda davom etaverasiz. Internet ulanganda barcha kiritilgan sonlar avtomatik ravishda boshqa noutbuklarga ham yetib boradi.
